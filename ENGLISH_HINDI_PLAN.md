# English & Hindi — World-Class Mastery Plan (v2)

## The Core Insight

English is the ONLY subject where knowing the content is not enough.

A student can memorize every quote in Macbeth, know every theme, every character arc — and still write a 4/10 essay because:
- Their structure is incoherent
- Their quotes are dropped without analysis
- Their thesis is vague ("Macbeth is a tragic hero")
- Their paragraphs don't build an argument

**Mastery in English = Knowledge + Skill + Feedback + Iteration**

| Component | Other Subjects | English/Hindi |
|---|---|---|
| Knowledge | Definitions, formulas | Texts, quotes, themes, grammar rules |
| Skill | Problem-solving | Writing, analysis, comprehension |
| Feedback | Right/wrong | Rubric-based, qualitative, iterative |
| Iteration | Retry with new numbers | Rewrite with feedback (same essay improved) |
| Assessment | Deterministic | Open-ended, judged on multiple criteria |

### 7. THEME TRACKER (per text)
```
TEXT: Julius Caesar
THEME: Ambition vs. Patriotism
WHERE IT APPEARS:
  - Act I: Cassius describes Caesar's ambition ("Why, man, he doth bestride the narrow world")
  - Act II: Brutus's soliloquy — fears Caesar's ambition will crown him
  - Act III: Caesar's "northern star" speech — ambition as inflexibility
  - Act III: Antony's speech — "Ambition should be made of sterner stuff"
  - Act IV: The conspirators' own ambition emerges (Cassius's corruption)
HOW IT DEVELOPS:
  The play starts with ambition as Caesar's flaw. But by Act IV, we see
  that the conspirators are also ambitious — Cassius for wealth, Brutus
  for honour. The theme shifts from "Caesar is ambitious" to "everyone
  is ambitious, but some hide it better."
QUOTES THAT EMBODY IT:
  - "I am constant as the northern star" (Caesar's ambition as rigidity)
  - "Not that I loved Caesar less, but that I loved Rome more" (patriotism as justification)
  - "The fault, dear Brutus, is not in our stars but in ourselves" (ambition as human nature)
```

### 8. LITERARY DEVICE LIBRARY
```
DEVICE: Dramatic Irony
DEFINITION: When the audience knows something the characters don't
EXAMPLE FROM PRESCRIBED TEXT:
  Julius Caesar Act II: The audience knows the conspirators are planning
  to kill Caesar, but Caesar does not. When Caesar says "I am constant
  as the northern star," the audience feels the tragedy — his constancy
  is about to be disproved by daggers.
EXAMPLE FROM OTHER LITERATURE:
  Romeo and Juliet: The audience knows Juliet is drugged, not dead.
  Romeo does not — he kills himself over a sleeping woman.
HOW TO IDENTIFY IN EXAM:
  Ask: "What does the audience know that the character doesn't?"
  If the answer creates tension or tragedy, it's dramatic irony.
HOW TO WRITE ABOUT IT:
  "Shakespeare uses dramatic irony when Caesar declares himself 'constant
  as the northern star' — the audience, aware of the conspiracy, knows
  his constancy is about to be shattered. This irony heightens the tragic
  effect because Caesar's confidence is precisely what dooms him."
```

# SOLVER & APP INTEGRATION PLAN — 6 PHASES

## Overview

Generate deterministic solvers + question/answer generators for ALL subjects (Class 1-12) using Claude, then wire everything into a working app. The solvers use a hybrid engine: SymPy + scipy + pre-computed tables + manual rules. No paid services. No LLM in the computation path. 50% competency-based questions (NEP 2020), 50% standard problems.

## Architecture: Hybrid Engine (Free, Commercially Viable)

### Tool Upgrades (All Free, All Production-Grade)

|-------|----------|----------|-----|
| Math input | Custom keypad + KaTeX | **MathLive** | Khan Academy-grade editable math field, contextual keyboard, LaTeX output, handles fractions/integrals/matrices natively. Saves building 6 custom components. MIT licensed. |

## How Students Input Math Equations

- Class 1 student typing "5 + 3"
- Class 8 student typing "x² + 2x + 1"
- Class 12 student typing "∫ sin(x) dx from 0 to π"
- Class 12 student typing a 3×3 matrix

### Input Validation (Before Solving)

Before sending to SymPy, the input is validated:
1. **Syntax check:** Can SymPy parse it? If not, show friendly error: "I couldn't understand that. Try using the keypad buttons."

3. **Reasonableness check:** Is it non-trivial? (e.g., not just "0" for a derivative problem)
4. **Preview confirmation:** Show the rendered math and ask "Is this what you meant?"

## Error Handling & Fallback Strategy

When the primary engine can't solve something, the system cascades through fallbacks:

```
Student input → SymEngine attempt (fast, C++ core)
    ↓
  Success? → Return step-by-step solution ✓
    ↓ No
  SymPy attempt (slower but more capable parser)
    ↓
  Success? → Return step-by-step solution ✓
    ↓ No
  Giac/Xcas attempt (handles hard integrals/ODEs)
    ↓
  Success? → Return step-by-step solution ✓
    ↓ No
  Pattern table lookup (pre-computed standard forms)
    ↓
  Found? → Return table result with steps ✓
    ↓ No
  scipy numerical solution (for definite integrals, ODEs, optimization)
    ↓
  Success? → Return numerical answer with "computed numerically" note ✓
    ↓ No
  Graceful fallback: "I couldn't solve this automatically.
  Here's the approach: [describe method]. Try breaking it into steps."
    ↓
  Log the failure for later improvement
```

**Rules:**
- Every solver operation has a 10-second timeout
- Failures are logged (not silently swallowed) for pattern improvement
- Student never sees a raw Python traceback — always a friendly message
- If a step fails mid-chain, previous steps are still shown
- Numerical fallback results are labeled "numerically approximated"

```
1. INITIAL PROBE — give 3 questions spanning the topic's sub-skills
   ↓
2. IDENTIFY WEAKNESS — which sub-skills failed?
   ↓

                computation gap (failed solve)?
   ↓
5. REMEDIATION PATH:
   - Concept gap → review prerequisite node + watch walkthrough
   - Procedural gap → practice variable extraction (guided examples)
   - Computation gap → practice with step-by-step solver
   ↓

   ↓
7. MASTERY CONFIRMATION — 3 consecutive correct = mastered
```

**Question selection algorithm:**
- Start with medium-difficulty questions (not too easy, not too hard)
- If correct → increase difficulty (find ceiling)
- If wrong → decrease difficulty (find floor)
- Target: 70% success rate zone (Zone of Proximal Development)
- Stop when: all sub-skills assessed OR 15 questions reached

## How Competency-Based Questions (NEP 2020) Get Solved

### The Core Insight

A deterministic solver CANNOT "read" a competency word problem and extract math from it. But it doesn't need to. **The student IS the extractor.** The competency is tested at the recognition and translation layers, not the computation layer.

### 4-Layer Competency Flow

```
Layer 1: PRESENT competency question (word problem with Indian context)
    "A Pune factory manufactures LED bulbs. Cost C(x)=0.5x²-10x+150,
     Revenue R(x)=-0.3x²+20x. Find production level maximizing profit.
     Justify it's a max. If ₹5/bulb tax is imposed, how does optimal
     production change?"
    ↓
Layer 2: THINKING QUESTION — "What mathematical approach solves this?"
    Options: [Differentiate → set to zero → check second derivative]
             [Integrate → set to zero]
             [Just evaluate at any point]
             [Find the determinant]
    Student must recognize: this is a max/min problem → calculus
    (This IS the competency test — can they identify the right math?)
    ↓
Layer 3: STRUCTURED INPUT — student extracts variables from the word problem
    Revenue function: [-0.3*x**2 + 20*x     ]  ← student extracts from text
    Cost function:    [0.5*x**2 - 10*x + 150]  ← student extracts from text
    (This tests: can they translate real-world context → math?)
    ↓
Layer 4: DETERMINISTIC SOLVE — SymPy computes with step-by-step output
    P(x) = R(x) - C(x) = -0.8x² + 30x - 150
    P'(x) = -1.6x + 30 = 0 → x = 18.75
    P''(x) = -1.6 < 0 → Maximum (second derivative test)
    P(18.75) = ₹130.80
    Justification: P''(x) < 0 means concave down → maximum
```

### How Each NEP 2020 Competency Skill Is Tested

| Competency Skill | How Tested | Where In Flow |
|---|---|---|
| Conceptual understanding | Thinking question: "What math applies?" | Layer 2 |
| Procedural fluency | Student extracts variables from word problem | Layer 3 |
| Application to real-world | Indian context scenarios (Pune factory, ₹5 tax, cricket stats) | Layer 1 |
| Analysis & reasoning | Multi-step chaining: P(x) → differentiate → solve → verify | Layer 4 |
| Justification | "Why is this a max?" → second derivative test in steps | Layer 4 output |
| Data interpretation | Tables/graphs in question → student extracts values | Layer 3 |
| Assertion-reasoning | "Assertion: X. Reason: Y. Correct?" format | Dedicated question type |
| Case-study based | Multi-part: A → B → C, each builds on previous | Problem chain |

### How "Explain Why" / "Justify" Parts Work

The solver's step-by-step output IS the justification:

```
Step 1: P(x) = R(x) - C(x) = -0.8x² + 30x - 150
  Rule: Profit = Revenue - Cost

Step 2: P'(x) = -1.6x + 30
  Rule: Power rule — d/dx[axⁿ] = n·a·xⁿ⁻¹

Step 3: P'(x) = 0 → x = 18.75
  Rule: Set derivative to zero for critical points

Step 4: P''(x) = -1.6 < 0
  Rule: Second derivative test — negative → concave down → MAXIMUM
  Justification: Since P''(x) < 0, function is concave down at x=18.75,
  therefore this critical point is a local maximum.

Step 5: P(18.75) = ₹130.80
  Answer: Maximum profit ₹130.80 at 18.75 units
```

### How Follow-Up Questions Work (Case Study Chains)

```
Follow-up thinking: "How does a per-unit tax affect cost?"
  Correct: "Adds to variable cost: new C(x) = old C(x) + 5x"

Follow-up input:
  New cost: [0.5*x**2 - 5*x + 150]  ← student must update
  → P_new(x) = -0.8x² + 25x - 150
  → x = 15.625 (production drops from 18.75 to 15.625)
```

### How Grading Works (No LLM Needed)

```
Student answer → NER Extractor → Interpreter Loop → Score

1. Numerical: "18.75" → SymPy verify: 18.75 == 18.75 ✓ (2 marks)
2. Justification: "second derivative negative" → keyword match ✓ (1 mark)
3. Follow-up: "15.625" → SymPy verify ✓ (2 marks)
4. Explanation: "tax increases cost" → keyword match ✓ (1 mark)
Total: 6/6
```

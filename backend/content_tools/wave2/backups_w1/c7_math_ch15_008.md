## ELI5
Rahul swears his equation 3x + 5 = 20 gives x = 5 notebooks. Do we argue, or do we check? Substituting 5 for x on both sides is the referee: the left side must read exactly what the right side reads. If the two totals match, the solution stands; if they disagree by even a little, it is back to the solving. Verification turns a claim into a proof - no guessing required.

## DEFINITION
Verifying solutions of equations is the process of testing whether a specific numerical value for an unknown variable makes both sides of an equation equal when substituted in place of that variable. It confirms the correctness of a solved linear equation by checking if the Left-Hand Side (LHS) equals the Right-Hand Side (RHS).
## COGNITIVE_LEVEL
apply
## MASTERY_CRITERIA
Can substitute a given value into both sides of a linear equation separately, perform arithmetic operations following the correct order of operations, and determine with mathematical justification whether the value is a valid solution.
## SCOPE_BOUNDARY
Covers checking integer, fractional, and decimal values in linear equations in one variable. It does not cover solving equations from scratch (which is handled in other nodes) or verifying systems of equations with multiple variables.
## WALKTHROUGH
Imagine buying notebooks at the stationer store where Rahul says the secret equation for the total cost is $3x + 5 = 20$, and he claims that $x = 5$ notebooks is the correct answer. How do we know for sure if Rahul is right without guessing? We learned in earlier classes how to substitute values into algebraic expressions and how to evaluate integers. Today, we will use that substitution skill to separate the equation into two independent parts: the Left-Hand Side (LHS) and the Right-Hand Side (RHS). The key insight is that if a number is truly the solution, putting it into the expression must balance both sides so that LHS equals RHS.

**Takeaway:** verification is substitution: work both sides separately and compare the two totals. **In the exam:** follow the order of operations on each side, then declare LHS equals RHS or name the mismatch honestly. **Check yourself:** check Rahul: 3 times 5 plus 5 must be computed on its own and held against 20 - let the arithmetic decide. **Why students miss it:** students substitute into one side only and declare victory - the flagged error. The definition of an equation demands both pans weigh the same; a claim is proved only when the left total and the right total match exactly, each computed honestly in its own right before the comparison.

## COMMON_MISCONCEPTION
Students often make the error of substituting the test value into only one side of the equation (usually the side containing the variable) and forgetting to evaluate or compare it with the other side (RHS). For example, given $4x - 1 = 15$ and test value $x = 4$, a student calculates $4(4) - 1 = 15$, sees the number 15, and incorrectly thinks "15 matches 15, so it works," without realizing they must substitute into both sides independently or maintain the strict balance across the equals sign.
## ON_FAILURE
If a student struggles, guide them to use a physical two-column layout on their page. Write "LHS =" on the left side and "RHS =" on the right side. Instruct them to draw a vertical line between them, substitute the value into each column completely independent of the other, and only compare the final numbers at the very end.

## WORKED_EXAMPLE_1
PROBLEM: Verify whether $x = 3$ is a solution for the equation $5x - 4 = 2x + 5$.
STEPS:
- step 1: Identify the Left-Hand Side (LHS) as $5x - 4$ and the Right-Hand Side (RHS) as $2x + 5$.
- step 2: Substitute the test value $x = 3$ into the Left-Hand Side: LHS = $5(3) - 4$.
- step 3: Evaluate LHS using multiplication and subtraction: LHS = $15 - 4 = 11$.
- step 4: Substitute the test value $x = 3$ into the Right-Hand Side: RHS = $2(3) + 5$.
- step 5: Evaluate RHS using multiplication and addition: RHS = $6 + 5 = 11$.
- step 6: Compare LHS and RHS: Since $11 = 11$, LHS = RHS, confirming $x = 3$ is a valid solution.
REASONING: By evaluating both sides independently with the same substituted value, we test if the equation holds true. Equal final values prove that the number satisfies the balance of the equation.
ANSWER: Yes, $x = 3$ is a solution because LHS = 11 and RHS = 11.
## WORKED_EXAMPLE_2
PROBLEM: Check if $y = -2$ is a solution for the equation $3(y + 4) = 2y + 6$.
STEPS:
- step 1: Separate the equation into LHS = $3(y + 4)$ and RHS = $2y + 6$.
- step 2: Substitute $y = -2$ into LHS: LHS = $3(-2 + 4)$.
- step 3: Simplify inside the brackets first using integer addition: $-2 + 4 = 2$, then multiply by 3 to get $3(2) = 6$.
- step 4: Substitute $y = -2$ into RHS: RHS = $2(-2) + 6$.
- step 5: Simplify RHS using integer multiplication and addition: $-4 + 6 = 2$.
- step 6: Compare LHS and RHS: LHS is 6, but RHS is 2. Since $6 \neq 2$, $y = -2$ is NOT a solution.
REASONING: Following the order of operations and integer rules ensures accurate substitution. A mismatch between LHS and RHS proves the test value fails to satisfy the equation.
ANSWER: No, $y = -2$ is not a solution because LHS = 6 and RHS = 2.
## WORKED_EXAMPLE_3
PROBLEM: A student solves an equation and finds $a = \frac{3}{4}$ for the equation $4a + 1 = 4$. Verify if this value is correct.
STEPS:
- step 1: Identify the Left-Hand Side as $4a + 1$ and the Right-Hand Side as $4$.
- step 2: Substitute $a = \frac{3}{4}$ into LHS: LHS = $4\left(\frac{3}{4}\right) + 1$.
- step 3: Multiply the whole number by the fraction: $4 \times \frac{3}{4} = \frac{12}{4} = 3$.
- step 4: Complete the addition on LHS: $3 + 1 = 4$.
- step 5: Observe the Right-Hand Side: RHS = $4$.
- step 6: Compare LHS and RHS: Since $4 = 4$, LHS = RHS, verifying that $a = \frac{3}{4}$ is correct.
REASONING: Fraction multiplication rules from Class 6 combined with standard substitution allow us to verify non-integer solutions accurately. Equal final outputs confirm the solution.
ANSWER: Yes, $a = \frac{3}{4}$ is a valid solution because LHS = 4 and RHS = 4.

## ELI5
A digit is like an actor: the face never changes, but the role grows with the stage. Line up four identical fives in one long number and every face reads five, yet the positions make them thousand, hundred, ten and one. The 500-rupee note, the 50-rupee note and the 5-rupee coin all carry the same face on different stages. Place value is the salary; face value is the name badge.

## DEFINITION
The face value of a digit is its own value regardless of its position, while the place value is the value of a digit based on its specific position (ones, tens, hundreds, thousands) in a number.
## COGNITIVE_LEVEL
understand
## MASTERY_CRITERIA
The student must correctly identify both the face value and the place value of any digit in a 5-digit number and express the number as a sum of its place values (expanded form).
## SCOPE_BOUNDARY
This topic covers place value and face value for whole numbers up to 5 digits in the Hindu-Arabic system. It excludes decimal place values, negative numbers, and bases other than 10.
## WALKTHROUGH
Imagine you are at a school store buying a pen. If you have a 500-rupee note, a 50-rupee note, and a 5-rupee coin, each '5' has a different meaning: one is worth five hundred, one is worth fifty, and one is worth five. To understand this, look at the position of the digit: start from the rightmost digit (the ones place) and move left to tens, hundreds, and thousands. The "face" of the digit is always the same (it always looks like 5), but its "power" or "place value" changes depending on where it sits in line. To find the place value, multiply the face value by the value of the position (e.g., 5 in the hundreds place is 5 × 100).

**Takeaway:** face value is the digit itself; place value is the digit's worth on its position's stage - ones, tens, hundreds, thousands. **In the exam:** in value questions, read the position first, then state both values separately for the same digit. **Check yourself:** line up the walkthrough's three fives - note, note, coin - and watch the stage resize each role. **Why students miss it:** students quote the digit and call it done - the same face on a bigger stage is a no to reading it small; position writes the pay cheque.

## DIAGNOSTIC_QUESTION_5

## DIAGNOSTIC_ANSWER_5
Yes, when a digit is in the ones place, its place value equals its face value (e.g., in 4,325, the 5 is in the ones place, so 5 × 1 = 5). An incorrect answer suggests the student thinks place value must always be larger than face value.

**A wrong answer (answering 'no') reveals the student overlooked the ones stage - in the ones position, place value and face value shake hands.**

## COMMON_MISCONCEPTION
Students often confuse the digit itself (face value) with its contribution to the total number (place value). For example, in 3,042, a student might say the place value of 0 is 0, which is correct, but they might struggle with 3,402 and say the 4 is worth 400 because they "see" it near the front, forgetting that the 0 occupies a place that must be accounted for.
## ON_FAILURE
If a student fails, have them draw a Place Value Table with columns for Thousands, Hundreds, Tens, and Ones. Ask them to write the number 3,402 into the table digit by digit. Then, have them write the value of each column head (1000, 100, 10, 1) above the digits and perform the multiplication (Digit × Value) to see the place value clearly.

## WORKED_EXAMPLE_1
PROBLEM: A shopkeeper has 4,528 marbles. What is the place value of the digit '5' and the digit '2'?
STEPS:
- step 1: Identify the digits and their positions in 4,528.
- step 2: 5 is in the hundreds place, 2 is in the tens place.
- step 3: Multiply the face value by the position: 5 × 100 and 2 × 10.
- step 4: Calculate: 500 and 20.
- step 5: Verify that the total sum of all place values matches the original number.
REASONING: By breaking the number into its positional components, we see that 5 represents 5 hundreds and 2 represents 2 tens, which is necessary to understand the full value of the quantity.
ANSWER: Place value of 5 is 500; place value of 2 is 20.
## WORKED_EXAMPLE_2
PROBLEM: In the number 7,039, what is the face value and place value of the digit '0'?
STEPS:
- step 1: Locate the digit '0' in 7,039.
- step 2: Note the position: the hundreds place.
- step 3: Apply the definition: Face value is always the digit itself.
- step 4: Calculate place value: 0 × 100 = 0.
- step 5: Confirm that the placeholder '0' indicates no hundreds are present.
REASONING: Even though the digit is in the hundreds place, the face value 0 means there is "nothing" to count in that position, resulting in a place value of zero.
ANSWER: Face value is 0; place value is 0.
## WORKED_EXAMPLE_3
PROBLEM: A student has two numbers: 3,456 and 6,543. Compare the place value of the digit '4' in both numbers.
STEPS:
- step 1: Find the '4' in 3,456 (hundreds place).
- step 2: Calculate its place value: 4 × 100 = 400.
- step 3: Find the '4' in 6,543 (tens place).
- step 4: Calculate its place value: 4 × 100 = 40.
- step 5: Compare 400 and 40.
REASONING: This shows that the same face value (4) can have different place values depending on its position in the number, confirming the Hindu-Arabic system rule.
ANSWER: The place value of 4 is 400 in 3,456 and 40 in 6,543; 400 is larger than 40.

COMPETENCY: Comparing and justifying

- step 2: Identify the next largest digit (5) for the hundreds position.
- step 3: Identify the next (2) for the tens position.
- step 4: Place the smallest (0) in the ones position.
ANSWER: The number is 8,520. To make a number largest, we must give the largest digit the highest place value (thousands), followed by the next largest in the hundreds, and so on.

DEFINITION: A spreadsheet is a computer application that organizes data in a grid of rows and columns forming cells, where each cell can hold a value (numeric, text, date), a formula (arithmetic expression starting with =), or a function (predefined calculation like SUM, IF, VLOOKUP), enabling automated calculation, what-if analysis, and structured reporting for accounting and financial decision-making.
WALKTHROUGH: Imagine you are the accountant for a small Delhi-based wholesale kirana store. The owner hands you a notebook with 200 daily sales entries — item name, quantity, unit price, date — and asks: "What was our total revenue last month? Which items sold above ₹5,000? How much GST did we collect at 18%?" Doing this manually with a calculator takes hours and risks errors. Open Excel: each row becomes one sale, columns become Item, Qty, Price, Date, Revenue (=Qty*Price), GST (=Revenue*18%). Suddenly, SUM(Revenue) gives monthly total, COUNTIF(Revenue,">5000") counts high-value items, and a PivotTable (next node) summarizes by item/category. This node teaches you the building blocks: how to structure that grid, write =B2*C2 correctly so it copies down 200 rows (relative reference), lock the GST rate cell with $F$1 (absolute reference), and name the rate cell "GST_Rate" for readability. Start by opening a blank workbook, press Ctrl+Home to reach A1, type headers in Row 1, enter 5 sample rows in Rows 2–6, then build your first formula in E2. The key insight: a spreadsheet is not a static table — it is a dynamic model where changing one input (e.g., GST rate from 18% to 12%) instantly ripples through all derived values.

D3 Q: You have GST rate 18% in cell G1. In column F you want GST Amount = Revenue × GST_Rate for rows 2 to 100. Write the formula for F2 using absolute referencing so it copies correctly down to F100. Then explain what happens if you mistakenly use relative reference =E2*G1 and copy down.
D3 A: Correct formula: =E2*$G$1 (or =E2*G$1 since only row must lock). When copied to F3, it becomes =E3*$G$1 — column G and row 1 stay fixed. You open the workbook, see the summary table in range B2:F10 on Sheet2, and realize printing the whole sheet would waste paper and hide the key figures. You need to define a print area, set landscape orientation so columns fit, add a header with the company name and page numbers, and preview before printing. This node teaches you to transform a working spreadsheet into a polished, print-ready report that communicates exactly what decision-makers need.
D1 Q: What is the default print behavior in Excel if no print area is defined?
D1 A: By default, Excel prints all data on the current worksheet (all cells with content). A wrong answer like "only the selected cells" or "only the visible screen area" reveals the student confuses print area with selection printing or screen capture, missing that Excel's default is the entire used range of the active sheet.
D2 Q: A student sets a print area as A1:D20, then later adds data in column E. They print and column E is missing. Why did this happen, and how to fix it?
D2 A: The print area is static — it does not auto-expand. The fix is to either redefine the print area to include column E (A1:E20) or use a dynamic named range with a table (Ctrl+T) which auto-expands. A wrong answer like "Excel updates print area automatically" shows misunderstanding of print area as a fixed reference, not a live range.
D3 Q: You have a wide dataset (columns A to Z) that must fit on one landscape page. Which Page Setup scaling option ensures all columns print on one page width-wise without manually adjusting column widths?
D3 A: In Page Setup → Scaling, select "Fit to: 1 page(s) wide by 99 pages tall" (or a large number for height). This forces horizontal compression to one page while allowing vertical flow. A wrong answer like "Adjust to 75%" shows the student doesn't know the "Fit to" feature, which is the standard way to handle wide reports in board exams.
D4 Q: Compare printing a non-contiguous range (e.g., A1:C10 and E1:G10) vs. printing the whole worksheet. How does Excel handle page breaks in each case?
D4 A: Non-contiguous ranges print on separate pages (each selection = new page). Whole worksheet prints continuously with automatic page breaks. A wrong answer like "they print side-by-side on one page" shows confusion — Excel never merges non-adjacent ranges horizontally; each Print Area selection starts a new page.
D5 Q: A report prints with "#####" in a date column even though the cell width looks fine on screen. The student widens the column, but the print preview still shows "#####". What is the likely cause and fix?
D5 A: The column width in Page Layout view or Print Preview differs from Normal view due to margins/scaling. Fix: adjust column width in Page Layout view (View → Page Layout) or use "AutoFit Column Width" in Page Layout. A wrong answer like "it's a formula error" shows confusion between display truncation (#####) and actual errors (#VALUE!, #REF!).

DEFINITION: A Pivot Table is an interactive data summarization tool that dynamically reorganizes and aggregates large datasets from a source list (database) into cross-tabulated reports by dragging fields into Row Labels, Column Labels, Values, and Report Filter areas, enabling multi-dimensional analysis without altering the original data.
WALKTHROUGH: Imagine you are the sales manager of "M/s Home Maker Ltd." with 500 rows of daily sales data across 7 products, 4 cities, and 3 salespersons for January. The owner asks: "Show me total sales by product for each city, but only for Salesperson A." You could manually filter and sum, but that's slow and error-prone. Instead, you insert a Pivot Table: drag 'Product' to Rows, 'City' to Columns, 'Sales Amount' to Values (set to Sum), and 'Salesperson' to Filters (select 'A'). Instantly, you get a cross-tabulated matrix. Now change the filter to 'B' — the report updates instantly. This is the power of Pivot Tables: dynamic, multi-dimensional summarization without formulas. We'll start by understanding the source data structure requirements, then build one-variable and two-variable data tables for sensitivity analysis, and finally master full Pivot Table creation and manipulation.

A wrong answer (e.g., "any selected range" or "data with merged header cells") reveals the student doesn't understand that Pivot Tables require a structured database format — Excel treats the first row as field names and each subsequent row as a record.

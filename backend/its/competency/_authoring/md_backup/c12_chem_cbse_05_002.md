## DEFINITION
IUPAC nomenclature of coordination compounds provides a systematic set of rules to name mononuclear coordination entities by identifying the central metal, its oxidation state (Roman numeral), the ligands (listed alphabetically with appropriate prefixes), and the counter ions, ensuring an unambiguous name-to-structure correspondence.

## COGNITIVE_LEVEL
apply

## MASTERY_CRITERIA
The student can (1) write the correct IUPAC name for any mononuclear coordination compound given its formula, and (2) write the correct formula for a compound given its IUPAC name, applying alphabetical ligand ordering, oxidation state assignment, and cationic/anionic metal name conventions without error.

## SCOPE_BOUNDARY
Covers IUPAC naming rules for mononuclear coordination compounds (cationic, anionic, neutral) including ligand naming (anionic –o/–ido, neutral special names, cationic), alphabetical ordering, prefixes (di/tri vs bis/tris), oxidation state in Roman numerals, and metal name change for anionic complexes (–ate). Does NOT cover polynuclear complexes, organometallic nomenclature beyond metal carbonyls, or the 2013 IUPAC "preferred IUPAC name" (PIN) revisions beyond NCERT scope.

## WALKTHROUGH
Observe a blister pack of the anticancer drug cisplatin — its generic name is *cis-diamminedichloridoplatinum(II)*, yet the trans isomer *transplatin* is inactive. This real-world consequence of precise naming motivates the need for rules. Begin by identifying the coordination sphere (inside square brackets) and counter ions (outside). List ligands alphabetically ignoring prefixes (di, bis), assign oxidation state to the metal using ligand charges, then assemble: cation name first (ligands + metal + oxidation state), then anion name. Connect to Werner's theory (c12_chem_cbse_05_001) where you learned to distinguish coordination sphere from counter ions. The key pattern: **ligands alphabetically → metal with oxidation state → counter ion**.

## DIAGNOSTIC_QUESTION_1
State the exact IUPAC rule for the order in which ligands are listed in the name of a coordination compound, and give the correct ligand name for NH₃ and H₂O.

## DIAGNOSTIC_ANSWER_1
Ligands are listed in **alphabetical order** of their names (ignoring multiplicative prefixes like di-, tri-, bis-, tris-). The ligand name for NH₃ is **ammine** (not ammonia) and for H₂O is **aqua** (not water). A wrong answer (e.g., "alphabetical order of formulas" or "ammonia/water") reveals the student is confusing chemical formula ordering with name ordering, or using common names instead of IUPAC ligand names — both cause systematic naming errors in board exams.

## DIAGNOSTIC_QUESTION_2
Explain why the complex K₃[Fe(CN)₆] is named *potassium hexacyanidoferrate(III)* while [Fe(CN)₆]⁴⁻ would be named *hexacyanidoferrate(II)*, focusing on the metal name change and oxidation state.

## DIAGNOSTIC_ANSWER_2
In anionic complexes, the metal name takes the **–ate** suffix (ferrate for Fe, cobaltate for Co, etc.) and the oxidation state is indicated in Roman numerals. For K₃[Fe(CN)₆], each CN⁻ is –1, total –6; three K⁺ give +3, so Fe must be +3 → ferrate(III). For [Fe(CN)₆]⁴⁻, total ligand charge –6, overall –4 → Fe is +2 → ferrate(II). A wrong answer (e.g., "iron(III) cyanide") shows the student misses the –ate convention for anionic complexes and treats ligands as counter ions.

## DIAGNOSTIC_QUESTION_3
Write the IUPAC name for [Co(NH₃)₅Cl]Cl₂. Show all steps: identify coordination sphere, ligand names, alphabetical order, oxidation state of Co, and final name.

## DIAGNOSTIC_ANSWER_3
**Steps**: (1) Coordination sphere: [Co(NH₃)₅Cl]²⁺ (two Cl⁻ counter ions). (2) Ligands: five NH₃ (ammine), one Cl⁻ (chlorido). (3) Alphabetical order: ammine (a) before chlorido (c) → pentaamminechlorido. (4) Oxidation state: let x = Co oxidation state; x + 0×5 + (–1) = +2 → x = +3. (5) Cationic complex → metal name = cobalt. **Name: pentaamminechloridocobalt(III) chloride**. A wrong answer (e.g., "chloridopentaamminecobalt(III) chloride") reveals failure to alphabetize ligand *names* (chlorido vs ammine) — a frequent 1-mark loss in boards.

## DIAGNOSTIC_QUESTION_4
Compare the names of [Ni(CO)₄] and [Ni(CN)₄]²⁻. Why does nickel become *nickelate* in the second but not the first? What prefix is used for four CO ligands?

## DIAGNOSTIC_ANSWER_4
[Ni(CO)₄] is **neutral** → metal name = nickel(0) → *tetracarbonylnickel(0)*. [Ni(CN)₄]²⁻ is **anionic** → metal name = nickelate(II) → *tetracyanidonickelate(II)*. Four CO ligands use prefix **tetra-** (not tetrakis) because "carbonyl" has no numerical prefix. A wrong answer (e.g., "tetracarbonylnickelate(0)") shows confusion between neutral and anionic complex naming conventions and misuse of tetrakis.

## DIAGNOSTIC_QUESTION_5
A student writes the name of K₂[PdCl₄] as *potassium tetrachloridopalladium(II)*. Evaluate this name and correct it if wrong.

## DIAGNOSTIC_ANSWER_5
**Incorrect**. The complex anion is [PdCl₄]²⁻ → metal must take –ate suffix: **palladate(II)**. Correct name: **potassium tetrachloridopalladate(II)**. The student's error: using elemental metal name for an anionic complex. This is a classic board-exam trap — the –ate suffix is mandatory for anionic coordination entities (except for a few metals with Latin-based names like ferrate, cuprate, argentate).

## DIAGNOSTIC_QUESTION_6
Design a mononuclear coordination compound that contains Cr(III), two bidentate ethane-1,2-diamine (en) ligands, and two chloride ligands, with one chloride as counter ion. Write its formula and IUPAC name. Predict its isomerism.

## DIAGNOSTIC_ANSWER_6
**Formula**: [CrCl₂(en)₂]Cl. **Name**: dichloridobis(ethane-1,2-diamine)chromium(III) chloride. **Isomerism**: Shows geometrical (cis/trans) and optical isomerism (cis is chiral). A poor answer (e.g., missing "bis", wrong oxidation state, or missing counter ion) reveals inability to handle polydentate ligand prefixes (bis/tris) and charge balance — a multi-concept failure.

## COMMON_MISCONCEPTION
Students **alphabetize ligand *formulas* (e.g., Cl before NH₃) instead of ligand *names* (ammine before chlorido)**. Example: [Co(NH₃)₄Cl₂]Cl incorrectly named *dichloridotetraamminecobalt(III) chloride* (Cl before NH₃) instead of correct *tetraamminedichloridocobalt(III) chloride*. This happens because they see "Cl" and "NH₃" in the formula and order by symbol. The rule explicitly says: **alphabetical order of ligand *names***. Another error: using "tetra" for ethane-1,2-diamine (a didentate ligand) instead of "bis" — prefixes di/tri are for simple ligands; bis/tris/tetrakis are for ligands whose names already contain a numerical prefix (like ethane-1,2-diamine) or are complex.

## WORKED_EXAMPLE_1
PROBLEM: Write the IUPAC name of the complex [Cr(NH₃)₃(H₂O)₃]Cl₃. This complex is used in chromium electroplating baths.
STEPS:
- Step 1: Identify the coordination sphere and counter ions. The square brackets enclose [Cr(NH₃)₃(H₂O)₃]³⁺; three Cl⁻ are counter ions.
- Step 2: List ligands with their IUPAC names. NH₃ = ammine (neutral), H₂O = aqua (neutral). There are three of each.
- Step 3: Order ligands alphabetically by name: "ammine" (a) comes before "aqua" (a) — but "ammine" vs "aqua": 'm' vs 'q', so ammine first. Use prefixes: triammine, triaqua.
- Step 4: Determine oxidation state of Cr. Let x = oxidation state. Ligands are neutral, so x = charge on complex ion = +3. Roman numeral: (III).
- Step 5: Assemble name: ligands alphabetically + metal name + oxidation state + counter anion name. Complex is cationic → metal name = chromium. Counter anion = chloride.
REASONING: Alphabetical ordering uses the full ligand name (ammine before aqua). Neutral complex cation takes elemental metal name. Oxidation state derived from charge balance. All steps follow IUPAC 2005 rules as per NCERT.
ANSWER: triamminetriaquachromium(III) chloride

## WORKED_EXAMPLE_2
PROBLEM: Write the formula for potassium tetrahydroxidozincate(II). This compound forms when Zn(OH)₂ dissolves in excess KOH.
STEPS:
- Step 1: Parse the name. "Potassium" = counter cation K⁺. "tetrahydroxidozincate(II)" = anionic complex [Zn(OH)₄]²⁻.
- Step 2: Identify ligands and metal. "tetrahydroxido" = four hydroxido ligands (OH⁻, anionic). "zincate(II)" = Zn in +2 oxidation state in an anionic complex (–ate suffix).
- Step 3: Calculate complex charge. Zn²⁺ + 4(OH⁻) = +2 – 4 = –2. So complex anion is [Zn(OH)₄]²⁻.
- Step 4: Balance with counter cation. K⁺ has +1 charge; need two K⁺ for each [Zn(OH)₄]²⁻.
- Step 5: Write formula with coordination sphere in square brackets: K₂[Zn(OH)₄].
REASONING: The –ate suffix signals anionic complex. Hydroxido is the IUPAC name for OH⁻ ligand (older name: hydroxo). Charge balance determines stoichiometry of counter ions.
ANSWER: K₂[Zn(OH)₄]

## WORKED_EXAMPLE_3
PROBLEM: A coordination compound has the formula [CoCl₂(en)₂]Cl. Write its IUPAC name, oxidation state of Co, coordination number, and predict the types of isomerism it exhibits. (en = ethane-1,2-diamine, a didentate neutral ligand). This is a classic JEE/NEET problem combining nomenclature, structure, and isomerism.
STEPS:
- Step 1: Identify coordination sphere: [CoCl₂(en)₂]⁺ (one Cl⁻ counter ion).
- Step 2: Ligands: two Cl⁻ (chlorido), two en (ethane-1,2-diamine). Both are didentate? No, Cl⁻ is unidentate, en is didentate.
- Step 3: Alphabetical order of ligand *names*: "chlorido" (c) before "ethane-1,2-diamine" (e). Prefixes: two chlorido → dichloro; two en → bis(ethane-1,2-diamine) [use bis because ligand name contains "di"].
- Step 4: Oxidation state of Co. Let x = Co oxidation state. x + 2(–1) + 2(0) = +1 (charge on complex cation) → x = +3.
- Step 5: Complex is cationic → metal name = cobalt. Counter ion = chloride.
- Step 6: Coordination number: 2 (from two Cl⁻) + 2×2 (from two didentate en) = 6.
- Step 7: Isomerism: Octahedral [Ma₂b₂] type with didentate ligands → geometrical (cis/trans) and optical (cis is chiral, exists as Λ/Δ enantiomers).
REASONING: Combines nomenclature rules (bis for didentate ligand with numerical prefix), oxidation state calculation, coordination number from denticity, and isomerism prediction — a multi-concept integration typical of competitive exams.
ANSWER: Name: dichloridobis(ethane-1,2-diamine)cobalt(III) chloride; Oxidation state: +3; Coordination number: 6; Isomerism: geometrical (cis/trans) and optical (cis enantiomers).

## COMPETENCY_QUESTION_1
QUESTION: The anticancer drug cisplatin has the formula [Pt(NH₃)₂Cl₂]. Its IUPAC name is *diamminedichloridoplatinum(II)*. A student argues that since the complex is neutral, the name should end with "platinum(0)". Evaluate the student's claim and explain the correct oxidation state assignment.
COMPETENCY: Evaluating chemical reasoning and oxidation state assignment in neutral complexes.
STEPS:
- Step 1: Recognize the complex is neutral (no counter ions).
- Step 2: Identify ligand charges: NH₃ = 0, Cl⁻ = –1 each.
- Step 3: Set up oxidation state equation: x + 2(0) + 2(–1) = 0 (overall charge).
- Step 4: Solve: x – 2 = 0 → x = +2.
- Step 5: Conclude: oxidation state is +2, not 0. The metal name in a neutral complex is the element name with oxidation state in Roman numerals (platinum(II)), not –ate suffix.
ANSWER: The student is incorrect. Oxidation state is +2, not 0. Neutral complex uses metal name with oxidation state (platinum(II)), not –ate. The name *diamminedichloridoplatinum(II)* is correct.

## COMPETENCY_QUESTION_2
QUESTION: The linkage isomers of [Co(NH₃)₅(NO₂)]²⁺ are named *pentaammine(nitrito-κN)cobalt(III)* and *pentaammine(nitrito-κO)cobalt(III)* in modern IUPAC (2005). However, NCERT uses the older notation: *pentaammine(nitrito-N)cobalt(III)* and *pentaammine(nitrito-O)cobalt(III)*. For the complex [Co(NH₃)₅(SCN)]²⁺, write the two linkage isomer names using NCERT convention and explain the structural difference.
COMPETENCY: Applying nomenclature to linkage isomerism and explaining bonding difference (analyze + create).
STEPS:
- Step 1: Identify ambidentate ligand: SCN⁻ can bind via S (thiocyanato) or N (isothiocyanato).
- Step 2: NCERT names: S-bonded = thiocyanato-S (or thiocyanato), N-bonded = thiocyanato-N (or isothiocyanato). NCERT Example 5.3(e) uses "thiocyanato-S" for S-bonded.
- Step 3: Write names: (i) pentaammine(thiocyanato-S)cobalt(III) for S-bonded; (ii) pentaammine(thiocyanato-N)cobalt(III) for N-bonded.
- Step 4: Structural difference: In thiocyanato-S, Co–S bond forms (thiocyanato); in thiocyanato-N, Co–N bond forms (isothiocyanato). Different donor atoms → different properties (IR, UV-Vis, reactivity).
ANSWER: (i) pentaammine(thiocyanato-S)cobalt(III) [Co–SCN]; (ii) pentaammine(thiocyanato-N)cobalt(III) [Co–NCS]. Difference: donor atom (S vs N) changes bonding, spectroscopy, and reactivity.

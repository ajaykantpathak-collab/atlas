DEFINITION: A set A is a subset of set B, denoted A ⊂ B, if and only if every element of A is also an element of B; formally, A ⊂ B ⇔ (∀x)(x ∈ A ⇒ x ∈ B). If A ⊂ B and A ≠ B (i.e., B contains at least one element not in A), then A is a proper subset of B and B is a superset of A. The empty set φ is a subset of every set, and every set is a subset of itself.
WALKTHROUGH: Imagine your school has a "Science Club" (set S) and a "Robotics Team" (set R). Every member of the Robotics Team is also in the Science Club, but the Science Club has additional members who only do biology projects. Ask: "Is the Robotics Team a subset of the Science Club?" Write down the defining condition: check each robotics member — are they in Science Club? If yes for all, then R ⊂ S. Since Science Club has extra members, R is a proper subset. Now consider: "Is the empty set a subset of the Science Club?" Since there are no members to check, the condition is vacuously true — φ ⊂ S. Finally, "Is Science Club a subset of itself?" Every member of S is in S, so S ⊂ S. This element-wise implication (x ∈ A ⇒ x ∈ B) is the single rule that decides every subset question.

DEFINITION: The sum of the first n terms of an Arithmetic Progression (AP) with first term a and common difference d is given by S_n = n/2 [2a + (n-1)d]. Equivalently, if the last term (nth term) is denoted by l, then S_n = n/2 (a + l). This formula calculates the total of all terms from the 1st to the nth term in an arithmetic sequence.
WALKTHROUGH: Imagine you are saving money every month for a school trip: you save ₹500 in the first month and increase your savings by ₹50 each subsequent month. After 12 months, how much will you have saved in total? This is exactly an AP sum problem where a = 500, d = 50, n = 12. To begin, always write down what is given: identify a, d, and n from the problem statement. Then decide which formula to use: if you know a and d, use S_n = n/2 [2a + (n-1)d]; if you know the first and last term, use S_n = n/2 (a + l). The key insight is that pairing the first and last term, second and second-last term, etc., each pair sums to the same value (a + l), and there are n/2 such pairs - this is the intuitive basis for the formula.

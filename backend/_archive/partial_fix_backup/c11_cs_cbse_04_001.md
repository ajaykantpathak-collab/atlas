## DIAGNOSTIC_QUESTION_1
What is the primary characteristic that distinguishes an interpreted language like Python from a compiled language like C++?

## DIAGNOSTIC_ANSWER_1
An interpreted language executes code line by line at runtime without a separate compilation step, while a compiled language translates the entire source code into machine code before execution. A wrong answer (e.g., "Python is faster") reveals confusion between interpretation and compilation, and a misunderstanding of the trade-offs (ease of debugging vs. execution speed).

## DIAGNOSTIC_QUESTION_2
Explain in your own words what "dynamic typing" means in Python and give a one-line code example that demonstrates it.

## DIAGNOSTIC_ANSWER_2
Dynamic typing means the type of a variable is determined at runtime and can change during execution; e.g., `x = 10` then `x = "hello"` is valid. A wrong answer (e.g., "variables must be declared with types") indicates the student is applying static typing concepts from languages like Java or C to Python.

## DIAGNOSTIC_QUESTION_3
A student writes a Python script to calculate the area of a circle. They run it and get an error. Which feature of Python allows them to fix the error and re-run immediately without a separate compilation step?

## DIAGNOSTIC_ANSWER_3
Python's interpreted nature allows immediate execution after editing; the interpreter reads and executes the script line by line. A wrong answer (e.g., "dynamic typing") confuses the feature that enables quick edit-run cycles with the feature that handles variable types.

## DIAGNOSTIC_QUESTION_4
Compare Python's memory management with that of C. How does Python's approach affect the programmer's responsibility?

## DIAGNOSTIC_ANSWER_4
Python uses automatic garbage collection, freeing the programmer from manual memory allocation/deallocation (like malloc/free in C). This reduces memory leaks but gives less control over memory layout. A wrong answer (e.g., "Python requires manual memory management") shows a fundamental misunderstanding of Python's runtime environment.

## DIAGNOSTIC_QUESTION_5
A team is choosing between Python and C for a high-frequency trading system where microseconds matter. Evaluate whether Python's features make it suitable or unsuitable, justifying your answer with at least two specific features.

## DIAGNOSTIC_ANSWER_5
Python is generally unsuitable due to its interpreted execution (slower than compiled C) and Global Interpreter Lock (limits true parallelism). However, its rapid development and rich libraries (e.g., NumPy) can be leveraged for prototyping. A wrong answer that ignores performance implications or claims Python is always faster reveals an inability to evaluate trade-offs in real-world contexts.

## COMMON_MISCONCEPTION
Students often believe Python is "just a scripting language" and not suitable for large applications, or they think "interpreted" means "slow for everything." They may also confuse dynamic typing with weak typing, assuming Python allows implicit type coercion like JavaScript (e.g., `"2" + 3` causing an error in Python but `"23"` in JS). This misconception arises from oversimplified introductions that emphasize ease of use over Python's robust type system and scalability (used in Instagram, YouTube).

PROBLEM: A student wants to write a Python program to calculate the total cost of 5 notebooks at ₹45 each and 3 pens at ₹15 each, then print the result. Identify which Python features make this task straightforward.
STEPS:
- Step 1: Recognize the problem requires arithmetic operations (multiplication and addition) and output.
- Step 2: Note Python's high-level syntax allows direct translation of the arithmetic expression: `total = 5 * 45 + 3 * 15`.
- Step 3: Observe that Python's dynamic typing automatically handles integer values without explicit type declaration.
- Step 4: Use the `print()` function from Python's extensive standard library to display the result.
- Step 5: Verify the output (₹270) matches manual calculation, confirming the interpreted execution gives immediate feedback.
REASONING: Python's high-level syntax reads like English, dynamic typing removes the need for `int` declarations, and the built-in `print` function simplifies output. Together, these features let the student focus on the problem logic rather than language mechanics.

## WORKED_EXAMPLE_2
PROBLEM: Compare how the same task (swapping two numbers) would be written in Python vs. C, highlighting Python's features that reduce code length.
STEPS:
- Step 1: In C, swapping requires a temporary variable and explicit type declarations: `int a=10, b=20, temp; temp=a; a=b; b=temp;`.
- Step 2: In Python, tuple unpacking allows swap in one line without temporary variable: `a, b = 10, 20; a, b = b, a`.
- Step 3: Identify the Python features used: dynamic typing (no type declarations), high-level data structures (tuples), and interpreted execution (immediate result in REPL).
- Step 4: Explain that Python's tuple packing/unpacking is a high-level abstraction that expresses intent directly.
- Step 5: Conclude that Python's design reduces boilerplate, making code more maintainable and less error-prone.
REASONING: The example contrasts low-level manual memory management in C with Python's high-level abstractions, illustrating how features like dynamic typing and built-in data structures increase productivity.
ANSWER: Python swap: `a, b = b, a` (uses tuple unpacking, dynamic typing, no declarations); C swap requires 5 lines with explicit types and temporary variable.

## WORKED_EXAMPLE_3
PROBLEM: A teacher wants to demonstrate Python's interpreted nature and dynamic typing by writing a program that takes a user's age (integer) and then later uses the same variable to store their name (string). Write the code and explain the features at each step.
STEPS:
- Step 1: Start Python interactive mode (REPL) to show immediate execution.
- Step 2: Input age as integer: `age = int(input("Enter age: "))` — demonstrates dynamic typing (variable `age` holds int) and built-in `input`/`int` functions.
- Step 3: Print age: `print("Age:", age)` — shows interpreted execution (immediate output).
- Step 4: Reassign `age` to a string: `age = input("Enter name: ")` — demonstrates dynamic typing (same variable now holds str).
- Step 5: Print name: `print("Name:", age)` — confirms the variable type changed at runtime.
- Step 6: Discuss that no recompilation is needed; the interpreter handles type change on the fly, unlike compiled languages.
REASONING: This example combines interactive mode (interpreted), dynamic typing (variable type change), and high-level I/O functions to show how Python's features support exploratory programming and rapid prototyping.
ANSWER: Code snippet run in REPL: 
```
age = int(input("Enter age: "))
print("Age:", age)
age = input("Enter name: ")
print("Name:", age)
```
Features demonstrated: interpreted (REPL), dynamic typing (age changes from int to str), high-level I/O.

## COMPETENCY_QUESTION_1
QUESTION: "Python is an interpreted, dynamically typed language." Explain what each term means and give one advantage and one disadvantage of each feature for a beginner learning programming.
COMPETENCY: Translating technical definitions into practical implications for learning.
STEPS:
- Step 1: Define interpreted: code executed line by line by an interpreter at runtime.
- Step 2: Advantage: immediate feedback, easy debugging; Disadvantage: slower execution speed.
- Step 3: Define dynamically typed: variable types determined at runtime, can change.
- Step 4: Advantage: flexibility, less syntax; Disadvantage: potential runtime type errors, harder to catch bugs early.
- Step 5: Synthesize: For a beginner, interpreted + dynamic typing lowers initial barrier but requires good testing habits.
ANSWER: Interpreted means no separate compile step; advantage: quick edit-run cycle, disadvantage: slower runtime. Dynamically typed means variables can hold any type; advantage: less boilerplate, disadvantage: type errors only caught at runtime. Both features make Python beginner-friendly but require discipline.

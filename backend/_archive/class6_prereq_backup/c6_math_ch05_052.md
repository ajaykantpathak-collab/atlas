## DEFINITION
A variable is a letter or symbol used to represent a number that can change or is currently unknown, while a constant is a fixed numerical value that does not change. Algebra is the branch of mathematics that uses these variables to describe patterns and relationships between numbers.
## COGNITIVE_LEVEL
understand
## MASTERY_CRITERIA
The student must be able to identify variables and constants within a simple algebraic expression and explain why a letter represents a changing value while a number remains fixed.
## SCOPE_BOUNDARY
This node covers the identification of variables and constants in simple algebraic expressions. It excludes solving for the value of variables, complex algebraic structures, or abstract algebraic proofs.
## WALKTHROUGH
Imagine you are at a fruit shop where the price of one apple is fixed at ₹10, but the total bill depends on how many apples you buy. If you buy 1 apple, you pay 10; for 2 apples, 20; for 3, 30. We can write this as 10 × n, where 'n' stands for the number of apples. Here, 10 is a constant because the price per apple never changes, while 'n' is a variable because it changes based on how many apples you pick. To identify them in any expression, ask yourself: "Does this number's value stay the same no matter what?" If yes, it's a constant. "Does this letter represent a value that could change?" If yes, it's a variable.
## DIAGNOSTIC_QUESTION_1
In the expression 5y + 8, which parts are constants and which is the variable?
## DIAGNOSTIC_ANSWER_1
The constants are 5 and 8, and the variable is y. A wrong answer suggests the student confuses coefficients (like 5) with variables; remind them that letters are the placeholders for unknown values.
## DIAGNOSTIC_QUESTION_2
If you have a box of toffees and you add 3 more, the total is t + 3. Why is 't' called a variable here?
## DIAGNOSTIC_ANSWER_2
't' is a variable because the number of toffees in the box is not fixed and could be any number. If the student says it is a fixed number, they have not yet grasped that letters in algebra represent unknown or changing quantities.
## DIAGNOSTIC_QUESTION_3
A rickshaw driver charges ₹20 for the ride plus ₹5 for every kilometer traveled. The total cost is 20 + 5k. If the distance 'k' changes, which part of the expression changes?
## DIAGNOSTIC_ANSWER_3
The part 5k changes as 'k' changes. Steps: 1. Identify k as the variable. 2. Recognize that multiplying 5 by a changing 'k' makes the result change. 3. Conclude 5k is the changing part. If the student identifies 20 as changing, they misunderstand the nature of a constant.
## DIAGNOSTIC_QUESTION_4
Compare 7x and 7. How does the presence of 'x' change the meaning of 7?
## DIAGNOSTIC_ANSWER_4
In '7', the value is fixed at seven. In '7x', the value depends on 'x' and can be 7, 14, 21, etc. A wrong answer shows failure to see that variables scale or define the scope of a constant.
## DIAGNOSTIC_QUESTION_5
Can a letter ever be a constant? (e.g., if we say 'p' is always 5).
## DIAGNOSTIC_ANSWER_5
No, by definition, a variable is for changing/unknown values. If 'p' is always 5, it is a constant, not a variable. Students often think letters *always* mean variables, ignoring the rule that the definition depends on behavior, not appearance.
## DIAGNOSTIC_QUESTION_6
Create an algebraic expression to represent the total weight of a school bag containing 2 kg of books and 'b' number of notebooks, each weighing 250 grams (0.25 kg).
## DIAGNOSTIC_ANSWER_6
The expression is 2 + 0.25b. A good answer includes the variable for the unknown number of notebooks and constants for the fixed weight. Poor answers confuse the constant (2 kg) with the variable part.
## COMMON_MISCONCEPTION
Students often confuse the "coefficient" (the number attached to a variable, like 5 in 5x) with the "variable" itself. They might say "5x is the variable," when only 'x' is the variable and 5 is a constant acting as a multiplier.
## ON_FAILURE
Ask the student to write the expression as an addition: x + x + x + x + x. Ask, "How many x's are there?" They will say 5. Point out that 'x' is the changing part, and the '5' simply tells us how many of that changing part we have. Show that the 5 never changes, but the value of x can be 1, 2, or 100.

## WORKED_EXAMPLE_1
PROBLEM: A milkman charges a fixed delivery fee of ₹15 and ₹40 per litre of milk. Write an expression for the total cost for 'L' litres of milk.
STEPS:
- Identify the fixed cost: ₹15 (this is a constant).
- Identify the variable cost: ₹40 per litre.
- Identify the unknown: 'L' is the number of litres (variable).
- Combine: 15 + 40 × L.
REASONING: The delivery fee doesn't change with milk quantity (constant), but the cost of milk multiplies by how many litres you buy (variable).
ANSWER: 15 + 40L
## WORKED_EXAMPLE_2
PROBLEM: In a cricket match, a player scores 6 runs for every 's' sixes hit and 4 runs for every 'f' fours hit. What is the total score?
STEPS:
- Identify the value of sixes: 6 runs per six.
- Identify the variable for sixes: 's'.
- Identify the value of fours: 4 runs per four.
- Identify the variable for fours: 'f'.
- Combine: 6s + 4f.
REASONING: We have two variables because the number of sixes and fours can change independently.
ANSWER: 6s + 4f
## WORKED_EXAMPLE_3
PROBLEM: A rectangular plot has a fixed width of 5 meters, but the length 'L' can be changed. Write an expression for the area, then identify the variable and constant.
STEPS:
- Area formula: Area = Length × Width.
- Substitute knowns: Area = L × 5 or 5L.
- Identify 'L': This is the variable (the length changes).
- Identify '5': This is the constant (the width is fixed).
REASONING: The area changes as the length changes, so the relationship is defined by the fixed width (constant) and the changing length (variable).
ANSWER: 5L; Variable: L, Constant: 5
## COMPETENCY_QUESTION_1
QUESTION: You have a piggy bank with ₹100. You add ₹20 every week for 'w' weeks. 
(a) Write the expression for the total money.
(b) If you stop adding money, is the '20' still a constant? Why?
COMPETENCY: Translating real-world situations to mathematical expressions.
STEPS:
- Define the starting amount as the constant (100).
- Define the rate of change as the coefficient (20).
- Define the variable as the time (w).
- Combine: 100 + 20w.
- Explain: Yes, 20 is a constant because it represents the fixed amount added weekly, even if the number of weeks changes.
ANSWER: (a) 100 + 20w (b) Yes, 20 is a constant because it is the fixed rate of addition.
DIFFICULTY: medium
## COMPETENCY_QUESTION_2
QUESTION: Compare the expressions "x + 5" and "5x". How do they differ in how the variable 'x' behaves?
COMPETENCY: Comparing and justifying.
STEPS:
- Analyze "x + 5": The variable 'x' is being increased by a constant amount.
- Analyze "5x": The variable 'x' is being scaled (multiplied) by a constant amount.
- Compare: Addition creates a "shift," while multiplication creates a "scale."
- Conclusion: They behave differently; if x=2, the first is 7, the second is 10.
ANSWER: In "x + 5", the variable increases by 5. In "5x", the variable's value is multiplied by 5, which changes the total much faster than addition.
DIFFICULTY: hard

## DEFINITION
A parallel circuit is an electrical arrangement where components are connected across the same two points, creating multiple independent paths for the electric current to flow. Each path receives the full voltage of the power source, allowing components to operate independently of one another.
## COGNITIVE_LEVEL
understand
## MASTERY_CRITERIA
The student must be able to predict that if one bulb is removed from a parallel circuit, the other(s) will remain lit, and explain why this happens by identifying the independent paths for the current.
## SCOPE_BOUNDARY
This node covers the definition and basic behavior of parallel circuits (independent paths and constant voltage). It excludes mathematical resistance calculations, Kirchhoff's laws, and AC/DC circuit analysis.
## WALKTHROUGH
Have you ever wondered why, if one light bulb in your house burns out, the rest of the lights in your room stay on? To understand this, imagine a highway that splits into two separate lanes, allowing cars to reach the same destination through different routes. If one lane is blocked, the cars simply take the other, open lane. In a parallel circuit, the electricity acts like those cars: it splits at a junction and travels through different branches to reach the components. Because each component has its own dedicated path back to the battery, the electrical flow remains uninterrupted even if a single branch is broken.
## DIAGNOSTIC_QUESTION_1
In a circuit with two light bulbs connected in parallel, what happens to the second bulb if the first bulb is removed?
## DIAGNOSTIC_ANSWER_1
The second bulb stays lit. A wrong answer suggests the student thinks electricity behaves like a single-lane road (series circuit) where one break stops the entire flow.
## DIAGNOSTIC_QUESTION_2
Why do homes use parallel circuits instead of one single path for all lights and appliances?
## DIAGNOSTIC_ANSWER_2
Homes use parallel circuits so that each appliance can be turned on or off independently and so that a failure in one device (like a bulb) does not cause the entire house to go dark. A wrong answer indicates the student does not understand the benefit of having independent paths.
## DIAGNOSTIC_QUESTION_3
If you connect two bulbs in parallel to a 9V battery, how much voltage does each bulb receive?
## DIAGNOSTIC_ANSWER_3
Each bulb receives the full 9V. A wrong answer suggests the student believes the voltage is "shared" or divided between branches, a common confusion with series circuit behavior.
## DIAGNOSTIC_QUESTION_4
If a circuit has three bulbs in parallel, and you add a fourth bulb in a new parallel branch, what happens to the existing three bulbs?
## DIAGNOSTIC_ANSWER_4
The existing three bulbs remain lit because they still have their own independent paths to the battery. A wrong answer reveals the student assumes that adding components always affects the operation of others, which is not the case in an ideal parallel setup.
## DIAGNOSTIC_QUESTION_5
Is it better to wire a Christmas tree light string in parallel or series if you want the other lights to stay on when one bulb fails?
## DIAGNOSTIC_ANSWER_5
Parallel is better because it ensures that a single failed bulb does not break the circuit for the rest. If a student chooses series, they are failing to apply the concept of "independent paths" to a practical problem.
## DIAGNOSTIC_QUESTION_6
Draw a diagram or describe how you would arrange two bulbs so that if one is unscrewed, the other remains shining.
## DIAGNOSTIC_ANSWER_6
The student must describe two separate loops connected to the same battery terminals. A poor answer would show a single loop (series), indicating a failure to grasp the physical layout of "separate branches."
## COMMON_MISCONCEPTION
Students often confuse parallel circuits with series circuits, believing that current must pass through one bulb to reach the next. They incorrectly assume that if one bulb is removed, the circuit is "broken" for everything, failing to visualize the multiple independent branches.
## ON_FAILURE
Ask the student to trace the path from the positive terminal of the battery to the bulb and back to the negative terminal using their finger. Have them repeat this for two bulbs side-by-side. Point out that if they trace one path and it never crosses the other bulb's path, they have successfully created a parallel circuit where the bulbs are independent.

## WORKED_EXAMPLE_1
PROBLEM: You have a 6V battery and two identical bulbs in parallel. Bulb A is connected to the battery. Bulb B is connected to the same battery in a separate branch. If Bulb A burns out, what is the status of Bulb B?
STEPS:
- 1: Identify the circuit type: Parallel (separate branches).
- 2: Recall property: In parallel, branches are independent.
- 3: Determine effect: Failure of one branch does not affect the other.
- 4: Conclusion: Bulb B continues to receive 6V.
REASONING: Since the path for Bulb B is physically separate from Bulb A, the broken filament in A does not interrupt the flow of electrons to B.
ANSWER: Bulb B remains lit.
## WORKED_EXAMPLE_2
PROBLEM: A student builds a circuit with a battery and two bulbs. The student notices that when they remove one bulb, the other stays on. Is this a series or parallel circuit?
STEPS:
- 1: Analyze the observed behavior: One component removed, other works.
- 2: Compare with definitions: Series circuits stop when one part is removed.
- 3: Compare with definitions: Parallel circuits provide independent paths.
- 4: Conclude: The behavior matches a parallel circuit.
REASONING: The independence of the bulbs confirms that there are multiple, separate paths for the current to travel, which is the definition of a parallel circuit.
ANSWER: It is a parallel circuit.
## WORKED_EXAMPLE_3
PROBLEM: Two bulbs are wired in parallel to a battery. A third bulb is added in a new branch. Does the voltage across the original two bulbs change?
STEPS:
- 1: Identify configuration: Parallel connection to a voltage source.
- 2: Recall property: Parallel branches share the same voltage as the source.
- 3: Add new branch: Connecting a new branch in parallel does not change the potential difference of the existing branches.
- 4: Conclusion: The voltage remains constant.
REASONING: In a parallel circuit, every branch is connected directly to the source terminals, keeping the voltage across each branch equal to the source voltage regardless of how many branches are added.
ANSWER: No, the voltage remains the same.
## COMPETENCY_QUESTION_1
QUESTION: Imagine a street lighting system where all lamps are on one long wire in a single loop. If a storm breaks the wire, what happens to all the lights? How would you change this to a parallel system, and why?
COMPETENCY: Comparing and justifying circuit designs.
STEPS:
- 1: Analyze single-loop scenario: This is a series circuit; one break stops current.
- 2: Propose parallel change: Connect each lamp to the main power lines via its own branch.
- 3: Justify: A break in one branch won't affect the others.
ANSWER: In the series system, all lights go out. In a parallel system, each light has an independent path, so if one branch breaks, the others remain illuminated.
DIFFICULTY: medium
## COMPETENCY_QUESTION_2
QUESTION: If you have 5 bulbs in parallel, and you add 10 more bulbs in parallel (15 total), what happens to the brightness of the first 5 bulbs? (Assume the battery is strong enough to power all).
COMPETENCY: Applying concepts to new situations.
STEPS:
- 1: Understand parallel properties: Each branch is independent.
- 2: Apply to voltage: The voltage provided to each branch remains the source voltage.
- 3: Evaluate brightness: Since voltage is constant, current through the original bulbs remains unchanged.
ANSWER: The brightness remains the same because each bulb in a parallel circuit receives the full, independent voltage from the source regardless of how many other bulbs are added.
DIFFICULTY: hard

# Standing waves — the harmonics of a fixed string

> subject: physics

- id: fixed_ends | label: Fixed ends | x: 0.040 | y: 0.300 | r: 0.035 | fn: both ends pinned — only whole half-waves fit

## explain
Pin a string at both ends and only whole half-waves fit: one loop for the fundamental, two for the second harmonic, three for the third. Nodes never move, antinodes swing hardest, and each added loop doubles, triples, quadruples the frequency — that's why a guitar string sings many notes at once.

## Sleeping giants (big value, bigger effort)

1. **NCERT PDF library (6.3 GB, in-tree)** — canonical textbook text/figures for every class; enable exact textbook citations, figure extraction, and a self-contained re-mining pipeline (finding #15, L).
2. **Study-pack feature from ~1,900 supporting files** — quote banks, revision sheets, character maps, model answers already authored for English 6-12 + electives; a parser + a few endpoints unlocks a whole study-material surface (finding #4, M-L).
3. **Auto diagram renderer from 5,402 hotspotted specs** — interactive SVG diagrams per node with zero new authoring (finding #3, M).
4. **545 no-sim chapters** — SIMS_COVERAGE gives the exact chapter list; a focused sim-authoring wave (or sim-to-catalog auto-matching) closes the biggest content gap (finding #1 extension, L).
5. **CISCE-only topic program (1,886 topics)** — makes the platform genuinely board-differentiated rather than CBSE+delta (finding #7, L).

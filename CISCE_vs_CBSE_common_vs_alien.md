**Excluding English and Hindi**

**Method:** Each CISCE topic is matched against ALL CBSE topics across ALL classes (C6-12).
A topic is "common" if CBSE teaches the same concept at any class level, even if at a different class.
A topic is "alien" only if CBSE has no corresponding topic at any class level.
